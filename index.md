# Professional Self-Assessment

## Introduction
I am Amber Rose. I have reached the completion of my Computer Science program, having worked and learned a great deal since beginning this journey since January of 2024. Along the way, I picked up a number of skills that will carry onto any field I apply myself to. I am currently employed as an Algebra Highshool teacher, and I plan to help my students understand how to think using logic, as the universe operates on a rule-based system. I hope to utilize my degree to not only teach my students skills that they will need in this technologically evolving landscape, but to create tools that can facilitate that process further.

## Reflecting on my Education
Throughout my Computer Science program at SNHU, I’ve learned to design and build complete, secure, and structured software systems. Completing coursework that taught me data stuctures, databases, software security, algorithms, and even gaming design, by my own selection, has helped me develop a stronger foundation in technical skill, problem-solving, and designing for user experience. More importantly, this Capstone allows me to reflect on all that I've learned and allowed me to apply that knowledge to demonstrate my ability to design scalable solutions, recognize and protect vulnerable software, and refactor code to promote efficiency while ackowledging trade-offs.

One of the biggest areas of growth for me has been understanding how different parts of a system work together. In earlier courses, I focused heavily on making code function correctly, but over time I learned to prioritize structure, maintainability, and efficiency. For example, in my Android Inventory application, I worked with databases, fragments, and session-based user roles to manage data dynamically. In my OpenGL project, I focused on improving rendering efficiency and structuring scene data in a way that reduces unnecessary computation. These experiences helped me understand how software engineering, algorithms, and data structures all connect in real systems rather than existing as separate topics.

Working on collaboration and communication has also been an important part of my development, even in mostly individual coursework. I learned how to document my decisions clearly, explain technical tradeoffs, and structure code so that another developer could understand and build on it. These skills are especially important when working with stakeholders or teams, where not everyone has a technical background. Being able to translate system behavior into understandable terms has helped me think more like a professional developer.

From a technical standpoint, I’ve gained experience in several core computer science areas. In algorithms and data structures, I learned how performance can change based on design choices, such as using maps versus linear structures for lookup efficiency. In software engineering, I focused on modular design, separating concerns using fragments and object-oriented structures. In database systems, I worked with SQLite to manage persistent user and inventory data, including role-based access control and query optimization. I also developed a stronger security mindset through practices like password hashing, input validation, and limiting user privileges based on roles.

Security became especially important as I started thinking more about real-world applications. Instead of just making systems work, I began considering how they could be misused or broken. Implementing hashed passwords and role-based access control in my Android application helped reinforce the importance of protecting user data and controlling system access.

My ePortfolio brings together three main artifacts: my Android Inventory Management application, my OpenGL scene rendering project, and my database-driven system design work. Each artifact represents a different area of computer science—software engineering, graphics and algorithmic rendering, and database management—but together they show my ability to build complete systems that integrate multiple disciplines. The Android project demonstrates application architecture and database integration, the OpenGL project demonstrates performance-conscious rendering and structured scene management, and the database work highlights how data persistence and structure support application functionality.

Overall, these experiences have helped me develop confidence in my ability to design, implement, and evaluate software systems. They have also shaped my professional goal of continuing to grow as a software developer, particularly in roles where I can work on full-stack systems or application development. This program has given me both the technical foundation and the problem-solving mindset needed to enter the field of computer science as a capable and adaptable developer.
